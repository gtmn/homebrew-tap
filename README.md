# gtmn's Homebrew tap

## Install

```bash
brew install gtmn/tap/<name>
```

Or `brew tap gtmn/tap` and then `brew install <name>`.

## What's in it

| Name | Kind | What it is |
|---|---|---|
| `claude-usage-meter` | formula | [Usage Meter](https://github.com/gtmn/claude-usage-meter), a menu bar meter for Claude Code limits. Built from source on install. |

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
